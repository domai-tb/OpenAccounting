## Coverage Notes

- This change maps 50 scenario rows to 49 unique executable tests across 48 spec scenarios covering SQLite precision, invoice arithmetic and lifecycle behavior, and document discounts. The correction-PDF artifact regression is owned by the separate document-correction change.
- The gross-mode Storno row verifies persisted mode and header signs, then checks that the PDF generator preserves signed values supplied in its snapshot. Production DB-to-PDF line mapping, artifact creation, path persistence, and original-date display belong to the separate correction-artifact regression.
- The run included all five added regression rows for discounted conversion, incoming Storno, per-position VAT, same-rate tie allocation, and gross-mode cent rounding.
- SQLite tests use the real Drift executor and verify accepted values round-trip and invalid values are rejected by application validation; SQLite itself does not enforce declared precision or scale.
- The shared allocation rows use the existing EÜR feature test file; invoice discounts use bucket totals for allocation and per-position VAT rounding.
