## Coverage Notes

- Every focused test SHALL use a configured in-memory `AppDatabase`, the real `createRouter`/`ShellRoute`, the exact localization wrapper below, and a `ProviderScope` override for the concrete `profileManagerProvider`. A deterministic `ProfileManager` subclass SHALL return controlled futures; the never-completing case SHALL use a `Completer` that is never completed.
- The route-smoke wrapper SHALL be equivalent to `MaterialApp.router(locale: locale, supportedLocales: AppLocalizations.supportedLocales, localizationsDelegates: AppLocalizations.localizationsDelegates, routerConfig: router)`. The test SHALL pass `Locale('de')` or `Locale('en')` explicitly; it SHALL not supply a partial delegate list, omit supported locales, or rely on an implicit fallback.
- The injected manager fixture SHALL return the unique marker `__settings_injected_profile__`, increment `activeProfileCalls` and `listProfilesCalls`, and expose `assertUsed()` that throws `StateError('injected ProfileManager was not used')` if either counter is zero. `test_settings_route_uses_injected_profile_manager` SHALL assert the marker, both counters equal one, and that `assertUsed()` does not throw. A production/default manager rendering `Default` cannot satisfy this test.
- `test_settings_route_uses_injected_profile_manager` SHALL navigate the real router to `/settings`, assert the marker/counters through the fast seam probe while red, and in the final acceptance call `await tester.pumpAndSettle()` with no timeout argument. It SHALL then assert `router.state.matchedLocation == '/settings'`, one `AppShell`, one `AppPage`, visible `__settings_injected_profile__` profile control, and `find.byType(LinearProgressIndicator)` is absent.
- `test_settings_profile_load_timeout_reaches_terminal_error` SHALL use the never-completing loader. Its red probe may use only `await tester.pumpAndSettle(timeout: const Duration(milliseconds: 250))` so the pre-fix non-settlement fails quickly. The final acceptance SHALL call only `await tester.pumpAndSettle()` with no timeout override, assert `/settings`, `AppShell`, and `AppPage`, assert the German `Profile konnten nicht geladen werden` message, assert the `Default` profile control is absent, and assert no `LinearProgressIndicator` remains after the exact `const Duration(seconds: 2)` deadline. It SHALL not increase the settle timeout, add a manual pump loop, disable animations, or skip `/settings`; retry action assertions belong to the retry scenarios below.
- `test_settings_profile_retry_recovers` SHALL first assert the route/shell/page, localized error, retry action, absent spinner, and absent `Default` control; its pre-fix red probe may use the 250-millisecond bounded settle. After making the injected manager resolve on its next load, the final acceptance SHALL activate the German `Erneut versuchen` action, call default `pumpAndSettle()` with no timeout argument, assert the error and retry action disappear, assert the injected profile marker or required `Default` recovery appears, assert `/settings`, `AppShell`, and `AppPage` remain, and assert no spinner remains.

The final acceptance SHALL call default `pumpAndSettle()` with no timeout argument and assert the same error and retry action return after another exact two-second bound, `Default` remains absent, `/settings`/`AppShell`/`AppPage` remain, and no spinner remains.
