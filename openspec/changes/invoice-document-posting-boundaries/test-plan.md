## Coverage Notes

The lifecycle fixtures use `AppDatabase.createTestDatabase()` and seeded number ranges. PDF identity, refusal-to-overwrite, and late artifact rollback tests use a real temporary profile directory. Existing unchanged-behavior scenarios may pass on the initial run; mark those green from baseline evidence, and require every newly introduced boundary/rollback scenario to fail before its implementation.
